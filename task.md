# Развёртывание OpenHands на Debian 13 (multi-user, isolated)

## Задача
Разверни на сервере Debian 13 OpenHands для трёх пользователей: `lapa`, `arni`, `kent`. Доступ — через браузер по HTTPS-поддоменам `lapa.aimcps.online`, `arni.aimcps.online`, `kent.aimcps.online`. На сервере уже установлен nginx — используй его как reverse-proxy.

## Требования
- **Изоляция пользователей.** У каждого — собственное рабочее пространство. Общая папка для совместной работы доступна всем трём, но не даёт выхода за свои пределы.
- **Без привилегий.** Пользователи `lapa`, `arni`, `kent` не должны иметь `sudo` или root-доступа.
- **Изоляция агентов.** Агенты не должны иметь возможности выходить за пределы назначенных им директорий (персональной и общей).
- **Защита от компрометации.** При получении злоумышленником доступа через агента он не должен нанести вред системе или получить доступ к данным других пользователей.
- **Доступ только через nginx.** Прямые порты OpenHands не должны быть доступны из интернета. TLS обязателен. Аутентификация на уровне nginx — обязательна.

## Ключевой контекст
Open-source OpenHands **не является multi-tenant** и не имеет встроенной аутентификации. Учитывай это при выборе архитектуры. Если для выполнения требований придётся запускать несколько экземпляров — раздели их по портам и поддоменам, как указано выше.

## Свобода реализации
Конкретные шаги, версии образов, способ организации reverse-proxy (включая нюансы работы sandbox-контейнеров через nginx), метод изоляции workspace и схему аутентификации выбери самостоятельно, исходя из текущего состояния системы. Перед изменениями проверь, что уже установлено и настроено, чтобы не ломать существующую конфигурацию.

## Критерии готовности
- Все три поддомена открываются по HTTPS, требуют аутентификации и ведут на изолированные экземпляры.
- Пользователи не имеют `sudo`/root.
- Агенты не могут выйти за пределы разрешённых директорий (подтверждено тестом).
- Прямые порты OpenHands недоступны извне.
- Общая папка работает для всех трёх пользователей, персональные — изолированы.
